This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**temp_corrections_acc** is a working repository for analyzing and applying a batch of English word corrections to the ACC (Aufrecht's Catalogus Catalogorum) dictionary. Also used for GST (Goldstücker) and BEN (Benfey) English word corrections.

## Architecture

| File | Purpose |
|---|---|
| `acc.txt` | ACC entries flagged for review |
| `acc_error.txt` | English spelling errors identified in ACC entries |
| `ben.txt` / `ben_error.txt` | BEN entries and errors |
| `ben_abwork.txt` / `ben_abwork_edit.txt` | BEN abbreviation correction work |
| `ben_error_todo5.txt` | BEN remaining error candidates to review |
| `gst.txt` / `gst_error.txt` | GST entries and errors |
| `ieg.txt` | IEG (Indian Epigraphical Glossary) entries |

## Workflow

1. Start from error lists (generated by the CORRECTIONS repo's English spell-check pipeline)
2. Cross-reference with other dictionaries to distinguish genuine errors from intentional usage
3. Apply confirmed corrections via `updateByLine.py` to `csl-orig` source files

## Dependencies

- **Python 3**
- **CORRECTIONS** sibling repo — source of the error lists
